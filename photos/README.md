# 自定义打卡点照片

把图片放到 `photos/路线名/打卡点名.jpg`,网站会自动加载。例如:

```
photos/
  苍岩山/
    景区南门.jpg
    桥楼殿.jpg
    福庆寺主殿.jpg
    公主峰观景台.jpg
    蝴蝶谷.jpg
    返回南门.jpg
  驼梁山/
    南台入口.jpg
    飞来石.jpg
    ...
```

**文件名必须与 [data.js](../data.js) 中 waypoint 的 `name` 字段完全一致**(含中文)。

**没图也没关系** —— 默认显示场景图标 + 风景描述,并提供一键搜索按钮(百度图片 / 小红书 / 高德地图)直接看真实照片。

**照片建议:**
- 比例:正方形(1:1)效果最好
- 尺寸:300×300 像素以上
- 大小:每张 < 200KB(用 [tinypng.com](https://tinypng.com) 压缩)
- 格式:`.jpg` 或 `.jpeg`(目前只识别 jpg 后缀,如需 png 改 [app.js](../app.js) 第 ~150 行 `photoSrc`)
